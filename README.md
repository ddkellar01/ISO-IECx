# ISO-IECx

Autonomous AI framework for crawling global ISO/IEC standards, studying requirements via Gemini, auditing system configurations, and orchestrating Google Flow video generation under strict 350-character constraints.

## Features
- **Scout Bots**: Automated extraction of ISO/IEC metadata and abstracts.
- **Learner & Synthesizer**: Gemini-driven semantic analysis and compliance study generation.
- **Compliance Evals**: Automated architecture auditing against ISO controls.
- **Google Flow Video Generation**: Automated video prompt formatting with strict 350-character limits.
